# v0.3.26

The Discord instance permission relay accepted WebSocket messages up to
128 MiB but disconnected when forwarding a message larger than 16 MiB.
Codex 0.163.0 returned a normal `plugin/list` response of 17,960,954 bytes
in the affected installation. The relay terminated the connection, the TUI
reconnected and fetched the same listing, and terminal contents were cleared
and redrawn roughly once per second. A newly created ephemeral conversation
could also become unavailable after the first disconnect.

The relay now uses one 128 MiB bound for accepted messages, pending writes,
and the queue used while connecting. Queue and socket backpressure remain
bounded; permission selection, RPC identity handling, Discord identity, and
source queues are unchanged.

A real WebSocket regression test forwards a plugin listing larger than 16 MiB
and verifies a subsequent request succeeds on the same connection. Existing
backpressure, concurrent permission, and lifecycle tests remain enabled.

This release includes the previously deployed persistent queue lock fixes,
bounded target hydration, exclusion of system title threads, prevention of
unmentioned bot reply loops, and transport dependency updates. Their branch
histories are retained in the release commit.

## Upgrade an existing alias, including Codex03 on another host

Finish the active task or hand it over and exit that alias's TUI normally.
Run the upgrade from a separate ordinary shell. Preserve its existing
`account.env`, `.env`, access policy, queues, receipts, and account home.
Use the alias's actual account home and configured marketplace name; do not
copy another alias's account or Discord state.

```bash
INSTANCE=codex03
ACCOUNT_HOME=/actual/codex03/account/home
CODEX_HOME="$ACCOUNT_HOME" codex plugin marketplace list --json
CODEX_HOME="$ACCOUNT_HOME" codex plugin list --json
```

If this repository is configured as `personal`, update that source:

```bash
CODEX_HOME="$ACCOUNT_HOME" codex plugin remove codex-discord-channel@personal
CODEX_HOME="$ACCOUNT_HOME" codex plugin marketplace remove personal
CODEX_HOME="$ACCOUNT_HOME" codex plugin marketplace add \
  zhshgmail/codex-discord-channel --ref v0.3.26
CODEX_HOME="$ACCOUNT_HOME" codex plugin add codex-discord-channel@personal
PLUGIN_ROOT="$ACCOUNT_HOME/plugins/cache/personal/codex-discord-channel/0.3.26"
test -x "$PLUGIN_ROOT/bin/codex-discord-instance"
```

Update the shell alias or wrapper to that exact launcher path, retaining its
existing instance name, account selection, and working-directory arguments.
Then launch the whole alias normally. In a fresh, idle session, verify it no
longer repeatedly reconnects or clears the terminal. Resume the intended old
session separately when desired. Confirm Discord receiving and reply delivery
with a real source on that host; local startup validation on another alias
does not establish its Discord delivery.

The tag commands apply after the release tag has been pushed. No operating
system restart or shared-daemon restart is needed for this plugin repair.
